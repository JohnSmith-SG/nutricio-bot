# Калорийный Бот — Telegram-нутрициолог с ИИ

Telegram-бот [@Nutricio_OlegTsu_Bot](https://t.me/Nutricio_OlegTsu_Bot): считает суточную норму
калорий по анкете, составляет с помощью нейросети меню на неделю, находит рецепты с переводом на
русский и видео, ведёт дневник веса и выгружает всё в Excel. Работает 24/7 на Linux-сервере.

*Telegram nutrition bot: calorie target (Mifflin–St Jeor), AI weekly meal plan, recipe search with
Russian translation and video, weight diary, Excel report. Python · aiogram 3 · SQLite · OpenAI-compatible API.*

## Возможности

| Кнопка | Что делает |
|---|---|
| 📋 Анкета и расчёт калорий | пол, возраст, вес, рост, активность, цель → базовый обмен (Миффлин — Сан-Жеор), норма с учётом активности и цели, БЖУ |
| 🍽 Меню на неделю | нейросеть подбирает блюда на 7 дней с живым индикатором прогресса; итоги считает код и подгоняет порции под норму |
| 🔍 Поиск рецептов | поиск по-русски в TheMealDB, перевод рецепта нейросетью, КБЖУ порции, русское видео с YouTube |
| ⭐ Мои рецепты | оценки 1–5 звёзд, избранное по рейтингу; любимые блюда учитываются в следующем меню |
| ⚖️ Дневник веса | запись веса, последние 7 записей и изменение от старта |
| 📊 Отчёт в Excel | книга `.xlsx`: профиль, меню на неделю, дневник веса с графиком, избранное |

## Решения, которые стоит отметить

- **Калории не доверяются модели.** Нейросеть даёт блюда, граммы и КБЖУ, а суммы по дням считает код и
  масштабирует порции под норму (шаг 10 г). Модель выбрана сравнением нескольких LLM
  (`tools/model_bench.py`): часть моделей «подгоняла» калории под цель.
- **Кэш ответов ИИ в SQLite.** Переводы рецептов и последнее меню хранятся в базе: повторный показ бесплатен и мгновенен.
- **Один адрес для всех моделей.** OpenAI-совместимый API (ProxyAPI): поставщик меняется одной переменной `NUTRICIO_MODEL`.
- **Секреты — только из окружения или файлов** (`*_FILE`), в коде и репозитории их нет.
- **Excel собирается в памяти** из базы и сразу уходит в чат, на сервере не хранится.

## Стек

Python 3.10+ · [aiogram 3](https://docs.aiogram.dev/) · SQLite (`sqlite3`) · openai (ProxyAPI) ·
openpyxl · TheMealDB API · YouTube Data API v3 · systemd.

## Структура

| Файл | Назначение |
|---|---|
| `bot.py` | Telegram-бот: меню, анкета (FSM), меню на неделю, поиск, рейтинг, дневник, отчёт |
| `nutrition.py` | формула Миффлина — Сан-Жеора, коэффициенты активности и цели, БЖУ |
| `ai.py` | нейросеть: меню на неделю (стриминг по дням), перевод рецептов и названий |
| `mealdb.py` | TheMealDB: поиск (словарь рус. → англ.), карточка рецепта |
| `youtube.py` | поиск русского видеорецепта |
| `storage.py` | SQLite: `profiles`, `favorites`, `weights`, кэш `recipes_ru` и `menus` |
| `export.py` | отчёт Excel (openpyxl) с графиком веса |
| `tools/` | проверки без Telegram: `smoke.py`, `excel_check.py`, сравнение моделей `model_bench.py` |
| `deploy/` | unit-файл systemd и зависимости для сервера |

## Запуск локально

```bash
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt     # Linux/macOS: .venv/bin/pip
# задать переменные из .env.example (BOT_TOKEN, PROXYAPI_KEY, YOUTUBE_API_KEY)
.venv/Scripts/python bot.py
```

Проверка дневника и Excel без Telegram и ИИ: `python tools/excel_check.py out.xlsx`.

## Сервер

`deploy/nutricio-bot.service` — служба systemd под отдельным пользователем без прав root:
`Restart=always`, ограничение памяти 300 МБ, ключи читаются из файлов (`BOT_TOKEN_FILE` и т. п.).
Бот занимает около 190 МБ памяти. База `nutricio.db` создаётся рядом с кодом при первом запуске.
